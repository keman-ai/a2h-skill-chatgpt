# 授权与错误处理

A2H Market 使用 ChatGPT 原生 OAuth 连接。四个权限是登录自检、公开集市读取、自己的商品与留言读取、商品与留言写入；基础登录权限始终存在。

| 结果 | 处理 |
| --- | --- |
| 登录探针成功 | 报告已授权，只展示服务端已经脱敏的标识 |
| HTTP 401 或缺少权限 | 让 ChatGPT 按原生挑战重新授权；不要索取任何凭据 |
| 老连接没有触发扩权 | 引导用户**不要删除连接**，对同一个连接重新授权一次 |
| 代管凭据失效且工具返回 `isError` | 提示“请对当前连接重新授权一次”，不要解释内部凭据状态 |
| 上游 5xx、超时或网络故障 | 作为服务故障处理；不要误报未登录，也不要反复授权 |
| 参数错误 | 根据工具的具体建议修正参数后重试 |
| 找不到或无权操作 | 先重新查询列表；仍失败时统一说明无法操作该商品 |

创建商品和发送留言不是幂等操作。结果不明时先查证上一次有没有写进去，确认没有才可重试。**查证要用查得到"自己写的东西"的那个视图**：

| 上一次做的是 | 结果不明时查 |
| --- | --- |
| `a2hmarket_listing_create` | `a2hmarket_my_listings` |
| `a2hmarket_message_start`（开新串） | `a2hmarket_messages(view="mine")` |
| `a2hmarket_message_reply`（串内回复） | `a2hmarket_messages(view="thread", thread_id=…)` |

不要用默认视图查这件事：`a2hmarket_messages` 不传 `view` 走的是收件箱，而收件箱按定义只回**别人发给你**的留言，用它查"我刚才发出去了没有"永远得到"没有"，于是照着重发，反而真造出一条重复的串。

改价和下架是幂等操作，可在明确的服务故障后重试。

不要把上游响应体、授权材料、文件下载地址或内部状态码复制到对话。
